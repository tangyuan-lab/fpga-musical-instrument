# 2026-10-17：硬件集成与发布验证

这一阶段把前面的音频播放链路继续向板级系统推进：先把采样来源从播放器中拆成同步存储接口，再验证外部 DDR3 接口的基本读写时序；随后加入 HDMI 状态显示和视频域快照；最后把仿真、综合记录和必须上板确认的项目分开整理。

## 内容

- `sample_store/`：A4 采样存储边界、播放器接口和 DDR3 mock 读写自检。
- `hdmi_status/`：1024×600 状态页、视频时序、TMDS/DVI 输出和状态快照跨时钟域。
- `release_verification/`：构建记录、硬件测试表、MCP3208 接线与发布前验证范围。

## 验证边界

`sample_store` 中的两个 ModelSim 脚本可以复现存储接口和 DDR3 mock 自检。`hdmi_status` 使用 Gowin PLL、OSER10 和 DVI TX 原语，当前完成 HDL 编译验证；Gowin 综合和真实显示器测试属于板级验证环节。`release_verification` 保存原工程记录，并标出未复现和必须上板确认的结论。

## 这一阶段的结论

采样播放器已经不依赖具体的片上 ROM 实现，后续可以替换为带预取缓存的外部存储接口；HDMI 状态页完成了视频域和系统域之间的快照隔离，但显示器兼容性仍需要真实硬件确认；发布资料现在按仿真、综合和上板三级证据分别记录。
