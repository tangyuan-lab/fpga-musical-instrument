## 三级验证

第一级是仿真能证明的。ModelSim 可以证明协议时序、包络形状、定点数缩放、饱和逻辑、跨时钟域
同步、状态机跳转。本仓库里能重跑的部分都附了 `.do` 脚本和 testbench，跑出来是什么就是什么。

它证明不了音色、听感、模拟链路的噪声，也证明不了真实 ADC 和真实 DDR3。

第二级是综合/布局布线能证明的。Gowin 可以证明资源占用、引脚分配、时钟约束下的 setup/hold
有没有违例、位流生成是否成功。本机没有安装 Gowin，因此本仓库未重跑综合和布局布线。Fmax、
BSRAM/DSP 占用、`PR1014` 警告和位流 SHA-256 均为原工程记录。

第三级是板级验证：耳机输出、力度手感、HDMI 锁定、空闲噪声、功放开关爆音和连续运行稳定性。
这些项目需要在真实硬件上测试。
