# Day 03：从单音到压力驱动的四声部

这是 FPGA 音频乐器的第三个发布阶段，接在 `day02-pr` 的 PT8211、48 kHz DDS、按键消抖和 ADSR 之后。
本阶段没有把“多声部”写成一个孤立的演示，而是沿着真实输入链路分成四个可定位的增量：

1. **双声部与四音循环**：先证明混音不会截断仍在发声的另一个声部，再把试听操作改成单键循环。
2. **MCP3208 双 ADC 扫描**：把两片 8 通道 ADC 的 SPI 协议和 16 路采样做成独立边界。
3. **压力键事件**：完成基线校准、低通、迟滞、力度归一化和掉线释音。
4. **四声部合成**：把压力事件分配给四个声部，用宽位累加和饱和保护输出。

## 本阶段的关键工程决策

### 先拆边界，再接整机

MCP3208 扫描器只产生 16 个 12 位采样和 `frame_valid`，不判断“哪个键按下”。这样 SPI 命令、通道顺序和压力判断可以分别验证；如果 ADC 返回全零，也不会被误判成按键逻辑错误。

两片 ADC 共用 SCLK/MOSI，但保留两根 MISO。成品模块的 DOUT 是否在 CS 拉高时可靠释放没有实测证据，多一根输入线换取明确的电气边界。

### 压力输入不是一个阈值比较器

压力矩阵先采 64 帧基线，再计算 `baseline - current`，经过一阶低通后使用 16/8 的按下/松开迟滞，最后映射到 0～255 力度。没有新采样时主动清除门控状态，避免 ADC 或 SPI 掉线造成“卡音”。

### 混音必须保留保护位

四路 16 位声部先在更宽的累加器中求和，最后再做 16 位饱和。直接截断会在满和弦时发生二补码回绕，听感是明显爆音。启动阶段保持静音，避免功放打开时把未初始化数据送出去。

## 可复现验证

在安装了 ModelSim/Questa 的环境中，从对应目录执行：

```powershell
cd C:\Users\26369\Desktop\day03-pr\sim\day03
vsim -c -do run_step4.do
vsim -c -do run_step5.do
vsim -c -do run_scan.do
```

本阶段已保留并整理的证据：

- 双键混音：检查松开一个键不会截断另一个声部；
- 四音循环：检查 A4/B4/C5/D5/A4 顺序、连续重触发和 +6 dB 后无削波；
- MCP3208：检查 24 位命令帧、两片 ADC 的 16 通道捕获和 `frame_valid` 握手；
- 压力键和四声部 RTL：完成源文件和接口整理，当前验证为编译级检查。

压力模块曾出现 S 脚达到 3.3 V 的过压风险。这个问题发生在 ADC 转换之前，不能靠 RTL 缩放解决；上板前必须确认模块处于模拟模式、供电和 S 脚电压满足 ADC 输入范围。
