# 2026-10-16：A4 音色对照

S2 按键交替触发采样 A4 和合成 A4，两档共用 PT8211、功放和输出接口。合成音数字幅度减半，使试听响度接近。

采样保持 48 kHz、单声道、约 1.5 秒，取录音左声道，约 1.8 kHz 以上提升 5 dB，峰值限制约 ±5000 PCM，末尾 80 ms 淡出。松键另有约 43 ms 淡出。

已有记录中采样/合成的串行峰值为 4998/3109，30–180 ms RMS 约 1595/1324，2 kHz 以上相对能量约 6.3%/4.6%。

执行 `vsim -c -do run_ab.do`，测试四次按键音源交替、左右声道一致、松键淡出、静音、复位与安全电平。打开 `2026-10-16_audio.gprj` 时顶层为 `top_sample_a4_ab`。

已有综合记录：Fmax 约 69.060 MHz，83/118 BSRAM，setup/hold 违规为 0。当前工程需重新综合确认。
