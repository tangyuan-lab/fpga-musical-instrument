# 2026-10-16：快速连按的连续性交接

快速连按时，前一次松键淡出仍可能带有非零幅度。若重新触发立即把输出清零，就会形成波形跳变。

`note_on` 保存当前输出到 `restart_from`。当绝对幅度超过 32 PCM 时，保持旧输出并在 32 个采样帧中交叠到新音；48 kHz 下约 0.67 ms。静音首次按键直接起音，顶层每次按键都启用长尾。

执行 `vsim -c -do run_retrigger.do`。testbench 使用加速帧节拍，分别验证静音起音、非零重触发、32 帧交接、幅度上限和复位静音。跳变数值适用于该测试激励。

已有工程记录：Fmax 62.888 MHz，104/118 BSRAM、3/118 DSP，setup/hold 违规为 0；板上反馈为连续按键无咔哒声、无丢音。当前整理后需重新构建与试听确认。
