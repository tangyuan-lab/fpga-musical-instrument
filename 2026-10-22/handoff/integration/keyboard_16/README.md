# 16 键映射接口

已提供 `key16_note_map.v` 与独立测试。键号 0～15 对应 C4～D#5，开启 `low_c3_mode` 后仅键0改为 C3（音色号16）。
音色号保留5位；按住期间改变模式，只影响下一次按下。松键必须沿用原实体键号。

**此处不含实体键盘扫描器**，没有确定 GPIO/行列接线，也尚未接入当前 K2/K3 试音顶层。
四声部引擎已在主工程内实现；仍需扫描器排队提供独立 key_id 的按下/松开事件并做四键实板验收。

运行：`python scripts/run_tests.py --suite basic`。测试覆盖32种键号/模式组合，不代表整个实体键盘已验证。
