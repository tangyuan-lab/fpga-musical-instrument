# 吉他合成方法与本次比较

这份报告比较本次实际实现的三个模型；FM、神经 DDSP 只作研究选型，不填造测试分数。

| 方法 | 本次实现或参考 | 结论 |
|---|---|---|
| 普通 Karplus–Strong | 随机初始激励、分数延迟、损耗循环，按参考衰减搜索增益 | 低资源基线 |
| 扩展 KS | 拨弦位置梳状激励、亮度滤波、分数延迟，三个固定频率解析琴体谐振器 | 有界竞争样机；只有一个弦振动方向，未完整拟合琴桥耦合 |
| 多衰减模态＋短瞬态 | 每音独立频率、相位、幅度、双/三衰减模态及短起音共振 | 当前参数化主线 |
| FM / 减法合成 | 少量运算器或滤波包络 | 未做同源拟合测试；首版要求逐谐波贴合，暂不采用 |
| 神经 DDSP | 可微谐波/噪声合成与控制模型 | 借鉴频谱损失；未训练或部署神经网络 |

## 相同输入与评分

代表音为 C3、D3、F#3、G3、C4、D#4；各架构使用同一录音、实测原调基频、有效时长与 RMS 标量匹配。
频谱指标是各 FFT 尺度的 spectral convergence 加 0.25 倍可靠频谱格点的对数幅度差。
FFT 尺度：256、512、1024、2048、4096、8192；起音 0–80ms、主体 80ms–1s、尾音 1s 至有效结束分别评价，再等权平均。
普通 KS 与扩展 KS 的循环增益都包含四个固定起点及参考衰减估计附近的校准点；扩展 KS 另搜索三组亮度/拨弦位置。
模态的 64/96 是预算上限，实际不足上限时不虚构额外振荡器。每个音完整的模态数和两档预算结果均在 fit JSON 中。

| 模型 | 六音平均误差 |
|---|---:|
| basic_ks | 1.317382 |
| extended_ks | 0.897897 |
| modal | 0.260062 |

选择规则：只有扩展 KS 平均误差至少降低 10% 且通过硬件和试听门槛时才换主线。当前结果支持保留模态主线。
联合微调使用稀疏多分辨率频谱与 RMS 的解析雅可比；只有完整分段误差改善且波形/包络不退化超过预设限度才保留。
这不是所有物理波导算法的上限，也不是独立录音泛化测试。尚未对吉他核心综合，资源数和 Fmax 不作实测声明。

## 纯硬件参数边界

导出的是有限解析振荡器参数及通用正弦数学表；不导出录音 PCM、录音残差、录音激励、录音 IR 或逐帧频谱。
STK Guitar 的可选 body file 路径不能直接搬入本工程；这里只参考弦/滤波结构。
首轮发现低电平预接触声会提前触发起点检测。本版重新定位正式拨弦，保留 2ms 余量，原 WAV 不修改，首轮结果留作历史。
输出按稳定段基频校准到 A4=440Hz，并保留原调拟合指标、校准比率和初始拨弦音高变化诊断。
