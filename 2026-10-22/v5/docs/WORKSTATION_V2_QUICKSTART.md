# V2 上位机快速使用

> 当前界面与V4工程操作请看 [音乐工作站使用说明](MUSIC_WORKSTATION_QUICKSTART.md)。下方V3界面说明保留为历史记录；旧959事件稿尚未通过原谱准确性验收。

## V3 新增操作（2026-10-17）

- 保存旧窗口里的修改后，双击根目录 `start_workstation_v2.bat`，窗口标题显示V3。打开 `build/imported_scores/Nocturne_D_Minor_连音修复_v3.fpgamusic` 可离线校正与试听，原PDF已嵌入；原开源校谱版仍保留。
- “五线谱”显示 Verovio 排版，可翻页、缩放、选音和高亮；音高、时长与卷帘、音符表共用同一编辑版本。复杂原稿的节奏修改使用“导出校谱 / MuseScore 打开 / 导回校正版”。旧时间线生成的谱面标为重新记谱。
- 电脑试听默认“参考乐器”（FluidSynth 钢琴），可选 SoundFont 和四声部 GM 乐器；“设备合成模型”用于试听波表、ADSR 和设备配器，二者音色不等价。比赛验证开关关闭电脑出声。
- 右侧修改音符属性；概览片段可拖动移动，Ctrl+拖动复制。保留 Ctrl+Z / Ctrl+Shift+Z。导回校谱保留资源 ID 和配器、增加版本，新音符仍待确认。
- “诊断与记录 → 音乐组件状态”查看安装情况。MuseScore构造样谱与《Nocturne》完整959音符演奏时间线往返均通过；原PDF仍用于人工核对，未确认音符不会自动下发。旧工程的重新记谱会在内存中升级，不覆盖原文件。组件重建：`python scripts/prepare_music_stack.py --install-python --with-musescore`。
- 格式 2 工程在 GUI 中默认另存 `_v3.fpgamusic`，保留旧文件。完整边界与测试见 [V3 实现与验收](OPEN_SOURCE_IMPLEMENTATION.md)。

## 离线编辑

1. 双击项目根目录 `start_workstation_v2.bat`。
2. 点“打开工程”，选择 `examples/workstation_v2_demo.fpgamusic`。
3. “编曲与校谱”默认显示钢琴卷帘和四声部时间概览；“原谱对照”查看 PDF/图片，“音符明细”修改精确数值。“音色库”可绘制单周期波表、编辑 ADSR；“分段配器”修改各段的四声部音色、音量及实体键音色。
4. 保存工程会保存当前音色参数及分段表中尚未提交的修改；关闭、打开、新建工程前会提示保存。保存本地工程不会发送音频或自动启动设备播放。

演示工程含两首歌曲：

| 曲谱 | 检查内容 |
| --- | --- |
| 十六键与分段音色 | C4～D#5 共16个音高，前8音使用“明亮拨弦”，后8音使用“柔和管音” |
| 四声部配器演示 | 主旋律、和弦、低音、鼓同时演奏，主歌与副歌切换配器 |

重新生成：`python scripts/create_workstation_v2_demo.py`。下发给 FPGA 的数据只有音符、参数及单周期波表。

## 电脑试听与卷帘校正（无需板卡）

1. 导入 PDF/图片后等待识谱，或直接打开已识别的工程；点击绿色“电脑试听”。未确认音符允许本机试听，不能直接下发设备。
2. 可暂停/继续、停止、拖动进度条或点击小节标尺/概览定位。暂停时定位仍保持暂停。调节速度、音量，或从下拉框选择实际扬声器/耳机。
3. 四声部分别有“静音/独奏”，便于只听旋律、和弦或低音。这里的开关只影响本机试听，修改后重新点试听；保存设备配器使用“分段配器”。
4. 拖动音符修改时间与音高，拖右端修改时长，下方力度竖条修改力度。双击空白添加音符，右键或 Delete 删除；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。编辑声部下拉框可只显示一个声部；Ctrl+滚轮或缩放条调整时间比例；隐藏“概览”可扩大编辑区域。
5. Ctrl+单击多个音符，再勾选“循环选中区间”，点击试听即可反复校对这段。卷帘与音符明细共用选择，听完后点击“确认选中”。编辑不会擅自确认识别结果。
6. 在“音色库”点击“电脑试听当前音色”，可直接听未保存的波表与 ADSR 草稿。设备试听使用另一个明确标注 FPGA 的按钮。

设备模型缓存于 `build/cache/preview_audio`，参考乐器缓存于 `build/cache/reference_audio`，重复试听复用缓存。设备模型支持段落音色及自定义波表，参考乐器使用各声部选择的 GM 乐器；两者支持速度、音量、移调与静音/独奏。电脑试听不能代替 FPGA 合成、I2S、延迟或满声部验收。本机单次最多20分钟，超限报错，不截断。

## 五线谱识别

已在 `build/tools/audiveris/runtime` 配置官方 Audiveris 5.11.0。缺少该目录时运行 `pwsh -NoProfile -File scripts/prepare_audiveris.ps1`，脚本校验官方包 SHA256 后在工程目录解包。

导入 PDF/图片后会自动启动“五线谱识别”，不需要再次点击按钮；“原谱对照”页可手动再次识别。对可完整定位的 MuseScore/Leland 3/4 双谱表矢量 PDF，优先直接读取 SMuFL 符号、符梁、谱号变化、附点、连音与延音曲线；其余谱面使用 Audiveris。矢量读取也要求人工确认，不以几何解析通过声称识谱完全准确。MusicXML 导入会报告小节超拍、拒绝跨空隙拼接延音，不把缺失的节奏隐藏为长音。

完成后对照原谱、卷帘与试听人工校正；选中校正后的音符再点“确认选中”。未确认的音符不能下发。原谱会嵌入 `.fpgamusic`。多页PDF可用“原谱页码”切换查看；选中带位置数据的音符后，“原谱对照”会自动切页并以红框标出音头。

《Nocturne》原先Audiveris版本有错：漏掉158速度、行内谱号和部分复杂连音。请打开 **`build/imported_scores/Nocturne_D_Minor_连音修复_v3.fpgamusic`**；原开源校谱版、矢量校正版和更旧待校正版均保留作对照。此版本修复重新记谱的MusicXML兼容性，959个PDF识谱音符仍须人工确认。

校正版读取4页102小节、1775个音头，合并816段同音延音为959个播放音符，速度158、PPQN1440以精确表示连音。开头四小节及29/46小节省略休止入口已有人工原谱锚点核对，全部音符仍保留待确认；这不表示整曲逐音人工确认。运行 `python scripts/verify_nocturne_pdf.py` 重建并检查，报告为 `build/tests/nocturne_audit/native_audit.json`。默认各轨同音色，避免把钢琴左右手擅自配成两种乐器。

官方 `zizi.png` 示例已完成实际识别与 MusicXML 导入，得到102个待确认音符；此结果不证明所有音高与节奏识别正确。复杂谱须继续人工校正。

## 连接 V2 后

此段操作的前提是 V2 位流通过布局布线/时序验收，并确认标准 I2S DAC 接线。当前板上可发声的旧位流继续保留，旧位流连接 V2 上位机会明确提示版本不匹配。

1. 选择 FPGA 的 USB UART（已验证板卡通常为 COM15），点“连接 FPGA”。USB 转 TTL 的屏幕串口不用于上传本协议资源。
2. 打开工程后点“下发整个工程”，等到资源 CRC 校验、目录读取全部成功。RAM 支持4首曲谱、8个自定义音色；容量超限会拒绝下发。
3. 在“设备演奏台”直接选择 FPGA 已确认的歌曲，点“播放设备曲谱”；这不依赖本机工程中有同一首歌。
4. 从设备音色列表选择内置或已下发音色，设置当前演奏音色或点击“FPGA 试听”。实体键配置为“跟随当前音色”时使用当前默认音色，固定音色的逐键配置优先。歌曲的分段配器可在下一段改变演奏音色。
5. 拖动进度条只预览，松手后定位；暂停时定位仍保持暂停。停止、换曲、返回首页执行清音。

设备目录的资源 ID 和版本用于确认选择；资源被替换后旧选择不会继续播放。目录、曲目进度和实体键当前音色显示来自 FPGA 回读。

## 下载与验收边界

- 此上位机不为板载 PT8211 生成右对齐音频。V2 采用标准 Philips I2S，外接 DAC 的型号与接线仍待确认。
- V2 串口屏 `.HMI` 已生成，官方 `.TFT` 编译、屏幕下载及实物联动仍待完成。
- 资源保存在 FPGA RAM；断开电脑后可独立演奏，断电后需重新下发。
- 整机模拟延迟、满负载及蓝牙/录音回传的状态见 `WORKSTATION_V2_STATUS.md`。
