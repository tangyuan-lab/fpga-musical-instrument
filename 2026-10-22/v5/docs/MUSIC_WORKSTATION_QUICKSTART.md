# 音乐工作站：当前版操作

## 启动

保存旧窗口的修改并关闭，双击项目根目录 **启动音乐工作站.bat**，标题显示V4。原 `start_workstation_v2.bat` 也可使用。
本轮无需重新烧录FPGA。电脑参考试听可离线使用，设备演奏需要匹配的FPGA及音频硬件。

## 四个工作区

| 工作区 | 用途 |
| --- | --- |
| 编曲 | 轨道概览、卷帘、力度、音符属性；顶部试听与定位 |
| 校谱 | 左侧原谱、右侧当前记谱；分别翻页、适宽、选音及外部校正 |
| 音色 | 单周期波表、ADSR，分别选择电脑或FPGA试听 |
| 设备 | 串口、资源目录、分段配器、设备播放、诊断 |

“视图”菜单可开关检查器，F11最大化编辑区。窄屏自动收起侧栏，低高度收起概览。顶部工具栏放不下的操作收在右侧展开按钮。

## 导入与电脑试听

1. `Ctrl+I` 导入 MIDI、MusicXML、PDF或图片。MIDI／MusicXML保留原始轨道，使用“编辑轨道”筛选；原始文件嵌入保存的工程。
2. 选择“参考乐器 · FluidSynth”，点击“试听”。可暂停、定位、调整速度、循环选中的音符。空格控制播放／暂停；文本输入框中的空格仍用于输入。
3. “试听 → 电脑试听设置 → 参考乐器设置”调整源轨道乐器、音量、静音及独奏。“保留原始乐器变化”使用导入的GM程序变化；改成固定乐器则覆盖该轨道的参考音色。
4. “设备合成模型”按设备映射和配器渲染，与参考乐器不同；有未映射轨道或不支持的控制事件会报告错误。
5. 比赛验证开关关闭电脑出声。电脑试听不作为FPGA合成、复音或延迟达标证据。

PDF／图片识谱仍是辅助结果。**《Nocturne》原有959事件稿未被证明正确，102小节逐音核对尚未完成。** 五／九连音不能因识谱退出成功或MusicXML可读取就认定正确。

## 校谱与保存

- 音高和力度可在卷帘、属性或谱面菜单编辑；未确认音符有提示，试听不自动确认。
- 导入原始MusicXML的节奏／声部结构修改暂用“校谱 → MuseScore 打开”，导出校正后再“导回校正版”。当前会阻止整曲重记谱覆盖原始调号、谱表或连音。
- MIDI与旧时间线的谱面是重新记谱，不等同于原始书面结构；可在卷帘改时间、长度及音高。
- 旧格式2／3工程默认另存为 `_v4.fpgamusic`，保留原文件；V4保存源轨道、控制事件和原谱。
- 后台识谱期间继续编辑不会被旧结果覆盖。冲突结果另存 `build/recognition_candidates/`，日志中提供路径。

## 下发到FPGA

1. “校谱 → 设备声部映射”明确每条源轨道对应主旋律／和弦／低音／鼓。
2. “设备 → 分段配器”选择各段的设备音色和音量。**GM参考乐器与SoundFont不作为设备音色上传。** 自定义设备音色仍使用单周期波表和合成参数。
3. 确认识谱音符，连接设备，再下发工程。未映射、超容量、同角色同音高叠置及未转换的MIDI控制器会阻止下发。
4. 原始MIDI踏板等事件已保留并可用于参考试听，尚未转换到设备编译器，不能忽略后当作相同演奏下发。

设备容量仍为4首歌曲、8个自定义音色、每首32段及2048个事件，共享64KiB。设备通过资源校验后才可用，电脑不发送演奏PCM。
