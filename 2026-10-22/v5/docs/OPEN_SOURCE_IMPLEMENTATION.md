## 设备资源与状态

- 保留 4 首歌曲、8 自定义音色、32 段、2048 音符、共享 64 KiB MIDI 缓存。
- FPGA 校验长度、CRC、MIDI 解析结果及曲长；歌曲与 UUID/版本匹配的分段配器联合提交后才发布为可用。
- 配器检查连续段落、曲长覆盖、已就绪音色、音量、移调范围；失败提交不覆盖已发布配器。
- 电脑先检查本地工程，再传完整 MIDI、单周期波表、参数及配器。设备不依赖持续逐音符或 PCM 流。
- 电脑回读 FPGA 实际设置；屏幕设置等待命令序号、操作码、值与辅助字段匹配后显示生效，其他来源的命令不能误确认本地草稿。

### 能力与 `RUNTIME_DETAILS (0x37)`

能力答复版本 3，18 字节；16..17 为小端特性位：bit0 运行详情，bit1 曲谱与配器联合发布。旧 16 字节能力答复和旧 `STATE (0x36)` 仍可读取。

新答复固定 80 字节，所有多字节整数为小端：

| 偏移 | 字段 |
| --- | --- |
| 0..4 | 请求操作码、结果、结构版本 1、最近命令操作码、最近命令结果 |
| 5 / 6..9 | 保留 / 最近命令执行序号 |
| 10..37 | 原来的 28 字节设备状态 |
| 38..45 | 四声部实际音色 / 音量，各 4 字节 |
| 46..51 | 静音掩码、独奏掩码、速度百分比 uint16、有效移调 int8、屏幕音色 |
| 52..59 | 循环 B 点 uint32、当前速度微秒/四分音符 uint32 |
| 60..67 | 当前读出音色的 ADSR，4 × uint16 |
| 68..79 | 快照序号、最近命令值、最近命令辅助值，各 uint32 |

屏幕通过 `rx0`..`rx39` 接收数据，`rx40` 为整份快照提交序号，界面只在提交后刷新。命令 32 位字段拆成 16 位传输，避免屏幕有符号数显示问题。目录和实际音色名由 FPGA 动态发送。
