# 2026-10-12工作站屏幕修正版

请用USART HMI打开本目录`instrument_workstation.HMI`，型号TJC1060X570_011、横屏1024×600。

- tmRestore周期为50ms，48个实体配置槽在约2.4s内恢复；全部定时器通过50..65535ms范围检查。
- 中文字库使用官方模板的子集模式2与小端uint16升序字形索引，已嵌入HMI；保留ASCII音高记号。
- 源码、事件及资源通过1166项检查；官方TFT编译和屏幕实测仍待完成。
- 编辑画布会显示各模式共用page0的控件。编译后点击“调试”，运行时应先显示中文四卡片首页，各模式互不叠加。
- 所有模式右上角“返回首页”可随时点击，立即停音并回到首页。

编译零错误后下载屏幕。下载期间断开FPGA C18→屏幕RX，USB-TTL TX接屏幕RX、RX接屏幕TX、共地，保持屏幕稳定5V供电。
完成后恢复C18→屏幕RX及共地；C19←屏幕TX需适配FPGA的3.3V输入电平。

配套升压型FPGA已于2026-10-12下载到SRAM。若单独验证实体键，松开所有键等待校准，按AB13两次进入弹琴模式，再按实体压力键。
官方导出的TFT可在项目根目录用`python scripts/collect_touch_tft.py --project instrument_workstation`收集。
