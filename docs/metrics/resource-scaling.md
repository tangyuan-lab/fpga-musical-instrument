# FPGA 资源与性能扩展记录

本文件记录同一套参数化架构在不同复音数下的资源、时序和满载输出表现，用于证明 FPGA 资源确实转化为有效复音、吞吐量、音质或效果。

## 测试一致性要求

每组数据必须注明：

- Git Commit；
- Gowin EDA 版本；
- 完整 FPGA 器件型号；
- 顶层模块和约束文件；
- 系统时钟、采样率和音频位深；
- 相位累加器位宽、波表深度和混音位宽；
- 是否使用 DSP、BRAM 以及共享或并行架构；
- 测试模式和满载持续时间。

除复音数外，比较组中的其他参数应保持一致。若参数变化，必须新建一组表格并解释原因。

## 吞吐量计算

官方评分口径采用：

```text
实时合成吞吐量 = 同时活跃且可闻的独立振荡器数 × 实际采样率
```

注意：

- 每个有效振荡器应具备独立相位状态、频率控制和包络控制。
- 同一个波形中的谐波不重复计算为复音。
- 过采样不会额外增加有效振荡器数量。
- 使用多频测试模式、输出频谱和 RTL 结构共同证明真实并行合成。

### 1 复音：单音 DDS 音源（按键 + ADSR）

- Commit：见单音 PR 合并后的 Commit
- Gowin 版本：V1.9.12.03（64-bit）
- 器件：GW5AT-60B（GW5AT-LV60PG484AC1/I0）
- 系统时钟：50 MHz
- 采样率 / 位深：48,000 Hz / 16 bit
- 架构参数：32 位相位累加器，4096 点 16 位波表（幅值 ±4096），相位步进 `39370534`；
  1 个声部直接送串口，还没有混音位宽；按键 5 ms 消抖，ADSR 由音频帧节拍驱动
- LUT / FF / DSP / BRAM：291 LUT + 14 ALU / 128 / 1（MULTALU27X18）/ 4（pROM）
- 最高频率 / 最差余量：97.975 MHz / 0.000 ns（约束 50 MHz，逻辑级数 4，setup 与 hold 违规端点都是 0）
- 输入到音频输出延迟：未测（还没有做延迟测量）
- 满载测试持续时间：仿真跑约 380 ms 连续音频，按键全程按住
- 输出是否稳定：仿真通过（ModelSim，从真实引脚解码并逐位比对正弦表）；上板未验证
- 频谱或上板证据：包络波形见 `docs/progress/2026-10-09_single-dds-voice/`
- 资源增加换来的有效能力：从 0 复音到 1 个按键触发的完整声部——独立相位、独立频率、带 ADSR
  包络，这是后续复音扩展的第一个可比较点
- 已知瓶颈与下一步：没有实测延迟；`PR1014` 提示仍在。Fmax 会随布局布线的结果浮动，同一份设计两次
  综合可能差几个百分点，这里记的是一次实测值。下一步做多声部与混音
