# 2026-10-12：多声部与压力输入链路

## 目标

把 day02 的单个按键单音声部扩展为可以承载压力键盘的输入和四声部输出，同时保持每个边界可独立验证。

## 里程碑

### 1. 双声部和四音循环

`audio_mixer_4ch.v` 保留额外累加位宽，最后统一缩放和饱和。双键版的 testbench 检查释放 S1 后 S2 仍继续输出；四音循环版使用一次按键切换 A4、B4、C5、D5，并验证相位连续、渐弱和 +6 dB 不削波。两套顶层和 testbench 都保留，便于追溯“为什么改设计”。

### 2. MCP3208 双片 SPI 扫描

两片 MCP3208 共用时钟和命令线，各自使用独立 MISO。扫描器每次转换发 24 个 SPI 时钟，完成 16 个通道后输出 `frame_valid`。`tb_mcp3208_scan.sv` 验证了命令帧在 SCLK 上升沿可被读取，以及恒定 MISO 输入能按通道顺序捕获。

### 3. 压力键矩阵

`pressure_key_matrix.sv` 将采样转换成按下、松开和 8 位力度；`button_filter.sv` 实现迟滞与滤波；`snapshot_cdc.sv` 负责把采样快照安全交给音频逻辑。基线校准采用 64 帧，默认按下/松开阈值为 16/8。

### 4. 四声部

`voice_allocator_4.sv` 管理最多四个活动音符，第五个事件需要抢占声部；`poly_synth_voice.sv` 保存每个声部独立的相位和包络；`poly_synth_4voice.sv` 使用保护位累加并在末端饱和；`audio_startup.sv` 负责上电静音。

## 已知问题和下一步

- `PRESS_FULL=2048` 是发布阶段参数，仍需要真实 FSR 曲线确认；当前 RTL 已完成编译检查。
- 四声部尚未在两片 ADC 到货后上板，资源、时序、分配和实际延迟待硬件测试。
- 下一步进入钢琴近似音色和真实 A4 采样对照，继续记录片上 RAM 与 Fmax 的变化。
