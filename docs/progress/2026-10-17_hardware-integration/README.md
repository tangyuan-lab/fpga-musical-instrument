# 2026-10-17 硬件集成与发布验证

本阶段承接 10 月 16 日的 A4 采样连续性实验，处理三个实际问题：采样数据如何从播放器中解耦、系统状态如何在板上可见、哪些结论可以进入发布记录。

## 工作结果

1. `sample_store` 将采样地址/数据定义为同步接口，播放器只处理播放位置、长尾、松键和重触发。
2. `sample_store` 增加 DDR3 用户接口的 mock 读写检查，验证 BL8 数据往返、错误检测和校准超时看门狗。
3. `hdmi_status` 将 ADC、音频就绪和音量状态通过快照跨到像素时钟域，避免视频逻辑直接读取 SPI 或音频实时总线。
4. `release_verification` 将可重跑仿真、历史综合记录和必须上板测试的内容分开，避免把导入记录写成当前验证结果。

## 当前范围

片上 ROM 仍是当前可运行的采样来源；DDR3 只完成 mock 接口自检，尚未接入预取缓存。HDMI 逻辑完成编译记录，但 1024×600 显示和 USB 触摸仍待真实设备确认。
