# 2026-10-09：单音 DDS 音源（按键 + ADSR）

这一步把第一天的方波测试音换成真正的单音正弦声部，并加上按键和包络。做完之后按住板上的 S2 就会发声，松开渐弱。分两段做：先修采样率并接入 DDS，再加按键、消抖和 ADSR。

## 先修一个算错的采样率

换 DDS 的时候我是照原来的思路做的：在 50 MHz 下每拍加 `48_000`，满 `50_000_000` 就发一次
采样请求。看起来没问题。

漏了一件事——PT8211 的 BCK 还是固定 1.5625 MHz。一个立体声帧是 32 个 BCK 周期，
`1_562_500 / 32 = 48_828.125`，串口每秒只能吃掉这么多帧，而累加器在按 48,000 Hz 生产样本。
两头速率对不上，板上实际是按 48,828.125 Hz 把样本取走的。音高偏了约 1.7%（大约 29 音分），但数
是错的，而且会随时间慢慢错位。

改法是不能只改累加器，BCK 得跟着一起改：一个立体声帧有 64 个 BCK 边沿，每拍累加 `48_000 × 64 = 3_072_000`，达到 `50_000_000` 就翻转一次并减去阈值；半周期在 16 和 17 个系统时钟之间分配，所以 BCK 不是严格等宽的，是分数分频；每 3 帧恰好占 3125 个系统时钟，`50_000_000 × 3 / 3125 = 48_000 Hz`，位时钟平均 1.536 MHz。

## DDS 声部

`rtl/audio/dds_sine_voice.v` 是 32 位相位累加器加一张 4096 点正弦表，幅值约 ±4096。相位步进
`39370534` 在 48 kHz 下正好是 440 Hz（算出来 440.000005 Hz）。

声部本身不生成采样节拍，而是用 `pt8211_tx` 输出的 `frame_tick` 更新相位。如果让它自己生成 48 kHz 节拍，音源和 DAC 就会有两套采样时钟，迟早漂移。这个 `frame_tick` 接口是第一天特意留出来的。ROM 用同步读方式访问，便于综合成块 RAM，实测综合出来是 4 个 BSRAM pROM。

## 按键与消抖

按键走 S2 / USER_BUTTON1，落在 AB13。低有效，和复位一样用 1.5 V IO 加内部上拉。

一开始我是想把按键电平直接接到音量乘法器上的。按一下会听到一串"嗒嗒嗒"的碎音——机械触点在手按下去的那几毫秒里会来回抖好几次，每次抖动都产生了一个新的音符事件。`rtl/audio/key_debounce.v` 先把按键同步进系统时钟域，然后等输入稳定够久（默认 5 ms 滤波）才产生一次 `note_on` 或 `note_off` 脉冲。

板上 `RECONFIG/SW7` 是重新加载 FPGA 配置的按键，不是逻辑复位。我一开始想拿它测复位，后来意识到按下去会把刚下载到 SRAM 的程序弄没，就改成只在仿真里验证逻辑复位。

## 包络的重新触发

`note_on` 到来时包络状态切到起音段。如果上一个音符还在释放过程中，电平还没降到零；只有从 `ADSR_IDLE` 重新开始时才把 `gain` 清零，还在释放中就从当前电平继续往上加，所以包络不会出现从非零直接跳到零的那一下。`adsr.v` 里那段注释写的就是这件事。

包络参数：起音约 5.3 ms，衰减到约 60% 持续音量需要约 68 ms，松键后从持续音量到静音约 205 ms；包络由音频帧节拍驱动，不是 50 MHz 系统时钟，所以它的时间常数跟着 DAC 采样率走。

## 验证方法

在 `sim/` 下执行两个脚本：

cd sim
vsim -c -do run_dds_sine.do        # DDS 与串行输出
vsim -c -do run_single_voice.do    # 按键、消抖、ADSR、复位

第一个从真实引脚解码 1600 帧，逐位和正弦表比对，同时检查 440 Hz 周期（相邻两次过零的间隔必须是 109 或 110 帧）、幅度、左右声道、分数分频的 BCK 周期（640 或 660 个时间单位）、每 3 帧 3125 个时钟。第二个跑约 380 ms 的音频过程，检查四件事：三次短促的触点抖动不能产生任何音符；稳定按键只产生一次起音；松键产生一次结束事件且包络渐弱到零；复位时功放关闭。

## 验证结果

- `run_dds_sine.do`：通过。`PASS: 48 kHz DDS sine and PT8211 serial output`，Errors 0。
- `run_single_voice.do`：通过。`PASS: key debounce, one DDS voice, ADSR, stereo PT8211 and reset`，
  Errors 0。
- Gowin 综合、布局布线、位流生成：通过。50 MHz 约束下 setup 与 hold 违规端点都是 0，TNS 0.000，
  Fmax 97.975 MHz，逻辑级数 4。资源是 4 个 BSRAM pROM 加 1 个 DSP 乘法器（MULTALU27X18），
  逻辑 305（291 LUT + 14 ALU），寄存器 128。
- 布局布线报 `PR1014`，`sys_clk_d` 走通用时钟布线，不是失败原因。
- 上板听感：没有验证过。仿真能证明协议和数据流，证明不了实际按键手感和听感。

## 已知问题

- 上板听感没有验证过：起音够不够快、松键有没有拖尾，都还只是仿真的结论。
