# 2026-10-13：项目 Day04 钢琴近似音色与音量调整

## 项目进度定位

本记录属于项目从 Day01 开始的第 4 个开发日。Day04 的成果是把前几日的压力驱动四声部推进为可辨认的钢琴近似音色，并完成提亮、音量和硬件问题定位。

目录名 `day04_timbre_v1`、`day04_timbre_bright` 和 `day04_volume_final` 表示 Day04 内部的三个阶段，不是项目日编号。

本日的内部演进顺序为：来源 阶段一（实时钢琴近似音色 v1）→ 阶段二（提亮音色 v2）→ 阶段三（琴槌噪声评估）→ 阶段四～阶段五（音量调整）。

## 目标

把 Day03 的正弦声部推进到可辨认的钢琴近似音色，并记录音色、音量和板上反馈之间的迭代关系。

## 版本演进

### Day04-阶段一：来源 阶段一，实时钢琴近似音色 v1

使用 `attack`、`body`、`tail` 三张 1024 点周期谐波表。起音表保留更多高次谐波，主体逐渐变柔，尾音继续衰减。FPGA 在音频帧节拍下推进 DDS、读取波表并连续混合三段频谱；力度同时控制起音响度和亮度。

验证覆盖四音顺序、起音/衰减/松键、力度差、复位静音和输出限幅。原工程记录的综合结果为 91.814 MHz、3 个 BSRAM 和 3 个 DSP。

### Day04-阶段二：来源 阶段二，提亮音色 v2

针对 Day04 阶段一的偏闷听感，增强起音、主体和尾音的 2～8 次谐波，减慢高频衰减，并对三张表做 RMS 归一化，让音色过渡期间的整体响度保持稳定。

串行 PCM 的 1.5 kHz 以上能量占比由 0.0410 提升到 0.1323，约 0.2 秒后由 0.0062 提升到 0.0633；四音峰值约由 22,580 增加到 24,870。原工程记录的综合结果为 106.276 MHz、3 个 BSRAM 和 3 个 DSP。

仿真声部的基频保持在 440 Hz 附近，没有出现周期性音高调制；板上听到的颤音需要结合模拟输出和供电链路定位。

### Day04-阶段三：来源 阶段三～阶段五，琴槌噪声评估与音量调整

琴槌噪声版通过了仿真中的音符、包络和限幅检查，板上出现起音咔哒和连续按键丢音，源码作为 `withdrawn_hammer_v3` 对照版本保留。

回退到 v2 后，音量经过两步调整：先降低 6 dB，再将 `GAIN_SHIFT` 降到 0，最终 PCM 峰值约为 6,219。两个版本的串行样本可逐帧比较，变化集中在幅度缩放。
