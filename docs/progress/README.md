# 开发进度记录

本页是评委和团队成员查看项目发展过程的统一入口。只记录已经发生的工作，不预填虚假成果；每个“已完成”状态必须有可以打开的验证证据和 Issue、PR 或 Release 链接。

## 状态定义

- `未开始`：还没有进入实施。
- `进行中`：已有 Issue 或功能分支，但尚未满足验收条件。
- `待审核`：已提交 PR，等待 Review 或补充证据。
- `已完成`：PR 已合并且验证通过。
- `受阻`：存在明确阻塞项，并已在 Issue 中记录原因和下一步。

## 每日更新格式

复制以下小节到本页下方，或在 `docs/progress/YYYY-MM-DD-主题/README.md` 中建立详细记录：

```markdown
### YYYY-MM-DD：里程碑名称

- 目标：
- 本日完成：
- 验证方法：
- 验证结果：
- 资源或时序变化：
- 证据链接：
- 关联 Issue / PR / Release：
- 已知问题：
- 下一步：
```

## 更新要求

1. 一个重要进展至少关联一个 Issue、一组代码或文档 Commit、一个 PR 和一份验证证据。
2. 学习阶段提交可复现的小实验、波形或上板结果，不提交大段复制的学习资料。
3. 图片旁写清测试配置、观察结果和结论，不能只贴截图。
4. 未通过的测试也保留，但必须说明原因和下一步。
5. 没有真实进展时不创建空 Commit。
