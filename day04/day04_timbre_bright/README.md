# Day 09：提亮钢琴近似音色

对应原始工程的 阶段二。目录里是 `piano_voice.v`（v2 声部）、三张 v2 谐波表在 `mem/`、
生成脚本 `generate_timbre_bright_tables.py`，顶层 `tang_mega_60k_top.v`，入口 `run_timbre_bright.do`。

Day04 阶段一的版本拿到板上试听之后，反馈是两句话：单音偏闷，像电吉他；板上听到颤音。

同一版本导出的 WAV 在电脑上没有出现颤音，仿真基频也保持稳定。

## 把它变亮

改动有四处，都是照着"闷"这个症状来的。增强起音、主体、尾音的第 2～8 次谐波，尤其是起音的
高频，让敲击感清楚一点。起音亮度衰减速度减半，高频留久一点；主体向尾音的过渡速度也减半。

三张周期表按相同 RMS 归一化，这条是我改的时候才意识到的：原来起音表谐波多，能量本来就大，
从起音过渡到主体的时候音量会往下掉一下，听着像是"敲下去之后突然缩了"，归一化之后过渡期间的
整体响度是平的。

效果在数字上是能看到的：首音 1.5 kHz 以上的频谱能量占比，从 v1 的 0.0410 提到 0.1323；
约 0.2 秒之后从 0.0062 提到 0.0633。串行 PCM 四音峰值从约 22,580 变成约 24,870。

首音 0.02–0.12 秒的 RMS 约 10,882，0.8–0.9 秒约 6,165，是衰减趋势。

## 颤音记录

我把首音的仿真 PCM 解调了一遍，基频稳定在约 440 Hz（439.9998–440.0003 Hz），没有看到数字
声部造成的周期性音高颤动。

本版本不加入失谐或 LFO。仿真基频稳定在约 440 Hz，板上颤音仍需结合模拟输出和供电链路定位。

## 验证

```powershell
vsim -c -do run_timbre_bright.do
```

testbench 和Day04 阶段一是同一个（`tb_阶段一.sv`），检查四音顺序、左右声道一致、力度差、自然衰减、
松键阻尼、复位静音和不削波。本次重跑通过。

该 testbench 覆盖包络、幅度和限幅；频谱数据表明高频能量增加，主观听感需要试听确认。
