# R6工程与编译说明

源码版本为`0x0b02fc49`。工程文件为`workstation_r6_piano32_bt.gprj`，顶层为`mega138_models8_top`。目标器件为`GW5AST-LV138PG484AC1/I0`、C版；使用Gowin FPGA Designer V1.9.12.03与SystemVerilog 2017。

## 工程操作

1. 完整解压源码包，在Gowin FPGA Designer中打开上述`.gprj`，保留工程内的相对目录。
2. 核对目标器件、顶层和工程选项：50MHz，place=3、route=2、route_maxfan=50。工程选项保存在`impl/workstation_r6_piano32_bt_process_config.json`，Tcl入口为`build.tcl`与`pnr.tcl`。
3. 在文件树中查看RTL、IP、初始化数据和约束；`sim`中的仿真模型与测试平台独立于生产编译清单。
4. 执行Synthesize，检查本次综合日志、资源用量及警告；随后执行Place & Route，查看本次布线、时钟与完整时序报告。
5. 输出基名为`workstation_nodrum_ddr`：综合输出位于`impl/gwsynthesis`，物理实现输出位于`impl/pnr`。位流文件扩展名为`.fs`，文本时序报告为`.tr`。

常规IDE编译直接使用包内文件，不依赖Python生成源文件。Tcl综合入口可用Gowin自带`gw_sh.exe build.tcl`执行，综合完成后使用`gw_sh.exe pnr.tcl`进入物理实现。运行其他Gowin构建时保持串行，避免输出目录或工具资源冲突。

结果检查包括未布通数、Setup/Hold/Recovery/Removal、时钟与复位、CDC例外、最小脉宽、DDR物理窗口、容量、器件及镜像身份。按本次实际生成的报告与镜像建立对应关系。

## 接口与功能

HC-05使用独立UART，D20接收模块TXD，C20发送至模块RXD；50MHz/5208，约9600波特、8N1。接线时按实际模块核对供电、电平、排针与板卡约束。蓝牙仅传输控制和状态，USB保留曲谱上传及急停。

钢琴递进为音色10、MIDI音高48..79，按100ms间隔逐个加入，按真实引擎接受和完成推进，32次完成后保持2秒并统一清音；背压可延后接受。保持原自然衰减、64模态和计算精度，原750ms失联保护保留。屏幕接口与会话匹配规则见`PIANO32_SCREEN_PROTOCOL_V1.md`。

硬件演示使用与目标匹配的SRAM加载方式，并核对镜像SHA、UserCode、回退及设备状态；不使用Flash写入。源码包的文件身份见`SOURCE_MANIFEST.json`与`build_identity.json`。

## 源码校验与仿真

两项工具使用 Python 3.10+ 标准库。从工程目录执行以下命令。也可从其他目录用工具的完整路径启动，源码和 ROM 按工程根目录解析。

```powershell
python scripts/check_project.py --json
python scripts/run_tests.py --test tb_fx_ram
python scripts/run_tests.py --test tb_bt_piano32_feedback --functional-effects-ram
```

仿真需要 ModelSim 的 `vlib`、`vlog`、`vsim` 和 Gowin GW5A 的 `IDE/simlib/gw5a/prim_sim.v`。可通过以下参数或环境变量指定本机路径。

| 依赖 | 命令行参数 | 环境变量 |
| --- | --- | --- |
| ModelSim 可执行文件目录 | `--modelsim-bin` | `MODELSIM_BIN`，也可使用 `PATH` |
| GW5A 原语模型文件 | `--gowin-prim-sim` | `GOWIN_PRIM_SIM`，也可设置 `GOWIN_HOME` 为 Gowin 安装目录 |
| ModelSim 基础配置 | `--modelsim-ini` | `MODELSIM_INI`，默认从 ModelSim 安装目录查找 |

默认使用 Gowin 厂商原语实现。指定 `--functional-effects-ram` 时，仅将效果 RAM 替换为随包提供的功能模型，其余 Gowin 原语继续使用厂商模型。

测试台参数可用 `--plusarg NAME` 或 `--plusarg NAME=VALUE` 传入，例如 `--plusarg PHASE_PS=250`。指定输入或输出文件时，相对路径从工程根目录解析。外部数据和输出文件可放在 `runs/`。

每次仿真写入独立的 `runs/<运行编号>/`，其中 `result.json` 记录模型选择、步骤退出码、有效检查数和日志校验值，`sim_completed.txt` 保存测试台完成记录，`source_hashes.json` 记录本次仿真输入。退出码 0 表示通过，1 表示运行失败，2 表示参数或工具配置错误。用 `--timeout-seconds` 调整每个外部进程的超时秒数。
