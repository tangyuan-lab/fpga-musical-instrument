# R6模块与结构说明

版本标识：`0x0b02fc49`。声音计算保持50MHz/48kHz、32声部、钢琴64模态及原精度，保留吉他19、Bass20与DDR相关路径。

| 源文件 | 职责 |
|---|---|
| `rtl/r7_piano32_progressive.sv` | 顺序调度音高48..79，按真实接受与完成推进，满32后保持并结束。 |
| `rtl/r7_test_piano32_control_r2.sv` | 将调度器接入测试中心与真实ready/done/result，保留停止、退出、急停和看门狗优先级。 |
| `rtl/field_test_models8_control_piano32_r2.sv` | 处理会话与普通命令，独立接收自动结束事件，处理自动结束与新命令同沿到达。 |
| `rtl/r7_piano32_screen_status.sv` | 核对请求身份并输出能力、构建、会话、阶段、真实完成数等同帧状态，最后提交快照序号。 |
| `rtl/r7_bt_control.sv` | 蓝牙会话、心跳、白名单和重放检查；宽等值比较采用分组组合树，保持协议同沿语义。 |
| `shared_modal_backend32.sv` | 在已有预取时点采样held位，保持声音计算周期、精度和自然衰减。 |
| `model_voice_control_models8_32.sv` | 空闲时采样事务数据并在事务期间保持，提交由实际握手约束，急停撤销有效状态。 |

原有播放器、单曲、DDR存储、压力输入、LED和屏幕逻辑在生产文件清单中保留。厂商IP与音源公式、数值精度保持原定义。生产编译清单见`sources.json`，引脚与时序定义见`constraints`。
