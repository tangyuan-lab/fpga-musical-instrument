## 打开和构建

1. 完整取得本日期目录，保持 `Gowin_BT_3664e98a/` 内的相对路径。在支持目标器件的 Gowin 环境中打开上述 `.gprj`。
2. 确认目标器件、顶层以及本工程自己的引脚／时序约束。60K 工程的器件、引脚和历史位流不适用于此入口。
3. 脚本构建时，先在 Gowin Tcl 环境执行 `build.tcl` 完成综合，再执行 `pnr.tcl`。后者读取前一步生成的 `impl/gwsynthesis/workstation_nodrum_ddr.vg`，不能在干净目录中直接跳过综合运行。
4. `runs/` 用于脚本写入终态文件，Git 通过 `.gitkeep` 保留该目录。新生成的网表、日志、波形和位流不纳入本次源码快照。

原包不含完整工具链、厂商仿真库或本版本的综合／布局布线报告。本次未运行 Gowin，也没有下载板卡；原构建身份用于核对来源，不表示本次重新构建通过。

## 目录与版本边界

`Gowin_BT_3664e98a/` 根目录和 `rtl/` 保存整机与服务模块，`ip/` 保存工程引用的 DDR3／PLL 依赖，`constraints/` 保存约束，`sim/` 保存测试台与参考模型。根目录的 `.mem` 是运行／合成所需数据，不能按临时文件删除；`sim/` 文件不应整体加入生产综合清单。

本包仅交付 FPGA 侧工程，不含新的上位机或串口屏 HMI 源码。10 月 22 日的上位机与屏幕工程仍是各自历史版本；本次没有验证它们与此版本的协议兼容性。各日期快照独立使用，不将不同架构的全部 RTL 混合编译。

`sim/result.svh` 要求相关测试传入 `+RESULT=<结果文件路径>` 并写入有效检查数。原包没有统一仿真运行脚本，部分测试依赖厂商原语／参考模型；78 个测试台已归档不表示 78 项已通过。

厂商 IP、原头部和构建身份原样保留，不解密受保护 IP；本次未为整个工程新增开源许可证。第三方 IP 的使用与再分发仍按其原授权条件处理。
